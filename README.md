# Weightlifting ANCOVA Analysis Repository

This repository contains materials for an ANCOVA (Analysis of Covariance) exercise using weightlifting data. The data compares deadlift performance (in kg) between experienced and inexperienced athletes, adjusting for bodyweight (in kg).

## Repository Contents

- **`ancova_weightlifting_file.mpx`**  
  The Minitab project file containing the dataset:  
  - Columns: `Deadlift_kg` (response), `Bodyweight_kg` (covariate), `Group` (factor: Experienced/Inexperienced).  
  Use this file to follow the analysis steps in Minitab.

- **`ancova_exercise.md`**  
  Step-by-step instructions for performing the ANCOVA in Minitab, including:  
  - Setting up the full ANCOVA model with interaction.  
  - Testing whether the regression slopes for each group differ significantly from a target value of 2.8.  
  - Results and conclusions from the example analysis.

- **`ancova_guide.md`**  
  A general guide explaining how ANCOVA works, its assumptions, interpretation, and when to use it (compared to ANOVA or regression).

## How to Use

1. Open `ancova_weightlifting_file.mpx` in Minitab.
2. Follow the instructions in `ancova_exercise.md` to run the ANCOVA and the separate slope tests.
3. Refer to `ancova_guide.md` for conceptual understanding of ANCOVA.
